## Signoff form for later use

Record decision (rehearsal GO/NO GO or production GO/NO GO), authorized scope/targets, source/script/artifact hashes, checklist revision, unresolved rows and approved exceptions, named approver/operators/backups, UTC window and evidence references. Exception approval cannot make an unexecuted test pass or override the schema-before-binary requirement. This form is unfilled; Phase 6A contains no release signoff.

6B may start only after disposable target/access, ownership, baseline/backup plan and explicit scope are supplied. Successful 6B supplies evidence for a new production decision; it does not automatically authorize 6C. Activation requires a separate decision after enrollment/reconciliation, even if deployment was authorized.
